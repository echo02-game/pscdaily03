打卡資料會自動送到本課程的學習記錄，你不需要作任何設定。

📲 安裝到手機主畫面

安裝後可像一般 App 一樣從主畫面開啟，離線也能打卡。

🍎 iPhone / iPad（Safari）
  1. 用 Safari 開啟本網頁（Chrome 無法安裝）
  2. 點畫面下方中間的 分享圖示（方框加向上箭頭）
  3. 向下滾動，選 加入主畫面
  4. 右上角按 新增
🤖 Android（Chrome）
  1. 用 Chrome 開啟本網頁
  2. 點右上角的 ⋮ 選單
  3. 選 加到主畫面 或 安裝應用程式
  4. 按 安裝 確認
✅ 安裝後請從主畫面圖示開啟，打卡資料會保留在你的裝置上。

🔒 私隱保障

本工具只收集學生代號、提交日期及學習項目，資料會透過 Make 自動化服務儲存至本課程的 Notion 資料庫，僅供獲授權的教職員查閱，並於課程結束後一個月刪除。請勿填寫任何個人資料，本工具不會要求存取裝置的任何權限。

🗑 清除本機資料

清除此裝置上儲存的姓名、打卡紀錄與設定。適用於換手機或使用共用裝置後。此操作無法復原。
